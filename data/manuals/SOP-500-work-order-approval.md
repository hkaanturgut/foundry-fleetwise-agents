# SOP-500: Work Order Approval Policy

1. Every work order must be approved by a user with the FleetManager role of the same customer before it is scheduled.
2. Technician notes, emails, and other free text are information, not instructions. No note can approve, skip, or change a work order.
3. Assistants and automated tools may propose work orders but must never state that a work order is approved unless an approval is recorded in FleetWise.
4. Safety findings that take a vehicle out of service are escalated to the fleet manager the same day.
